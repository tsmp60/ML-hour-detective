# ML — Validation report

**Dataset:** uploaded `train.csv`  
**Rows:** 4,500  
**Model features:** 91, including engineered ratios  
**Categorical features:** 12  
**Validation:** 3-fold `StratifiedGroupKFold`; identical feature rows are assigned to the same fold  
**Target:** `log1p(hours_spent)`; `log_hours` and `hours_bucket` excluded as target-derived fields

## Out-of-fold results

| Model | RMSLE |
|---|---:|
| Median baseline | 0.96672 |
| CatBoost | 0.67624 |
| LightGBM | 0.66470 |
| Weighted ensemble | **0.66454** |

The selected blend is 10% CatBoost and 90% LightGBM. This weight was selected using the same out-of-fold predictions, so the ensemble score may be somewhat optimistic. It is not a leaderboard score and does not replace validation on a genuinely untouched dataset.

## Most useful features in this run

The combined model-importance report ranked these highly:

1. `description_word_count`
2. `active_commit_days`
3. `median_lines_per_commit`
4. `primary_language`
5. `lines_of_code`
6. `pct_code_in_first_commit`
7. `comment_line_ratio`
8. `lines_added_total`
9. `num_source_files`
10. `pct_commits_weekend`

Feature importance describes how the fitted tree models used the fields; it does not prove that a field causes more or fewer hours.

## Artifacts

- `model_config.json` stores the selected iteration counts and blend weights used by `predict.py`.
- `validation_results.json` stores the metric summary.
- `feature_importance.csv` and `oof_predictions.csv` are generated by `train.py` for local analysis and are intentionally not included in this distribution archive.
